# 🚀 Portfólio | Pedro Castro

Bem-vindo ao meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minha trajetória, habilidades técnicas e os projetos que venho construindo como desenvolvedor. Com foco em uma experiência de usuário (UX) premium, utilizei técnicas modernas de design e animação para criar um ambiente que reflete minha paixão por tecnologia e inovação.

![Pedro Castro Hero Section](src/public/static/img/logo/pedro_banner.png)

## 💡 Sobre o Projeto

Este portfólio não é apenas uma lista de projetos, mas uma demonstração técnica de como unir estética e funcionalidade. O design segue uma abordagem **Motion-Driven** e **Glassmorphism**, focando em interações fluidas e uma interface limpa e moderna que destaca o que realmente importa: a solução e a tecnologia.

### ✨ Diferenciais Técnicos

- **Design Premium**: Interface baseada em Glassmorphism com desfoque de fundo (backdrop-blur) e transparências sutis.
- **Animações Fluidas**: Utilização de `Framer Motion` para entradas suaves, efeitos de paralaxe e micro-interações que tornam a navegação viva.
- **Infinite Stack Carousel**: Um carrossel de tecnologias infinito desenvolvido com CSS performático, permitindo que recrutadores vejam meu stack de forma dinâmica com pausa inteligente ao passar o mouse.
- **Integração com GitHub API**: Projetos buscados em tempo real diretamente do meu repositório oficial.
- **Responsividade Total**: Otimizado para garantir uma experiência perfeita desde monitores ultrawide até dispositivos móveis de tela pequena.

## 🛠️ Tecnologias e Ferramentas

O projeto foi construído utilizando as ferramentas mais modernas do ecossistema Web atual:

- **Core**: [React.js](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/) (Velocidade de desenvolvimento e build otimizado)
- **Styling**: [Stitches](https://stitches.dev/) (CSS-in-JS de alta performance)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Ícones**: [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment**: Configurado para ambientes modernos de CI/CD.

## 🚀 Como Executar o Projeto

Caso queira analisar o código localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/pedrocastro210/portfolio-pedrocastro.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou
   yarn dev
   ```
